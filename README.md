# Intelligent Forest Advisory Multi-Structure Decision System (IFAMDS)

A C++ AI advisory system for forest management using multiple data structures.

## What it does
Models forest advisory decisions using linked lists, trees, graphs, queues, arrays, and hash tables for efficient data management and decision-making.

## Tech Stack
- C++
- - Multiple data structures: linked lists, trees, graphs, hash tables, queues
 
  - ## How to Run
  - 1. Clone the repo
    2. 2. Compile: `g++ main.cpp -o ifamds`
       3. 3. Run: `./ifamds`
         
          4. ## Modules
          5. - Arrays, Linked Lists, Queues
             - - Trees (decision trees)
               - - Graphs (forest network)
                 - - Hash Tables
                   - - Monitoring system
